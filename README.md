# Free SEO tools — index

A curated index of the 31 free SEO utilities published at **[TML SEO Tools](https://tmlseo.freedev.app)**. No account is needed for the tools, and each one works from data you supply or from a public page it fetches, so the output can be checked rather than taken on trust.

## Keyword research

- [Keyword Generator](https://tmlseo.freedev.app/tools/keyword-generator) — turn a seed topic into a starting keyword list.
- [Keyword Density Checker](https://tmlseo.freedev.app/tools/keyword-density-checker) — term frequency against total word count.
- [Keyword Suggestions](https://tmlseo.freedev.app/tools/keyword-suggestions) — related phrases worth adding to a list.
- [Long Tail Keyword Generator](https://tmlseo.freedev.app/tools/long-tail-keyword-generator) — multi-word query ideas with lower competition.
- [Keyword Grouping Tool](https://tmlseo.freedev.app/tools/keyword-grouping-tool) — cluster a long list by the words it shares.

## Website SEO analysis

- [Website SEO Checker](https://tmlseo.freedev.app/tools/website-seo-checker) — fetch a page and report what search engines actually receive.
- [SEO Score Checker](https://tmlseo.freedev.app/tools/seo-score-checker) — weighted on-page score with the fixes that move it.
- [Broken Link Checker](https://tmlseo.freedev.app/tools/broken-link-checker) — crawl a page's links and find dead targets.
- [Website Page Size Checker](https://tmlseo.freedev.app/tools/website-page-size-checker) — HTML and asset weight of a URL.
- [Website Status Checker](https://tmlseo.freedev.app/tools/website-status-checker) — HTTP status and the redirect chain behind it.
- [GA4 Tag Checker](https://tmlseo.freedev.app/tools/ga4-tag-checker) — detect gtag.js and GTM containers, and whether consent is handled.

## Meta tags

- [Meta Tag Generator](https://tmlseo.freedev.app/tools/meta-tag-generator) — title, description, canonical and robots tags.
- [Meta Tag Analyzer](https://tmlseo.freedev.app/tools/meta-tag-analyzer) — audit the tags a page already has.
- [Open Graph Generator](https://tmlseo.freedev.app/tools/open-graph-generator) — Open Graph and Twitter card markup.
- [SERP Snippet Preview](https://tmlseo.freedev.app/tools/serp-snippet-preview) — how a title and description will look in results.

## Backlinks

- [Backlink Checker](https://tmlseo.freedev.app/tools/backlink-checker) — review the link data you already have.
- [Domain Authority Lookup](https://tmlseo.freedev.app/tools/domain-authority-lookup) — look up authority metrics for a domain.
- [Referring Domain Checker](https://tmlseo.freedev.app/tools/referring-domain-checker) — group and dedupe the domains pointing at you.
- [Anchor Text Analyzer](https://tmlseo.freedev.app/tools/anchor-text-analyzer) — see which anchors are over- or under-used.

## Technical SEO

- [XML Sitemap Generator](https://tmlseo.freedev.app/tools/xml-sitemap-generator) — build a valid sitemap from a URL list.
- [Robots.txt Generator](https://tmlseo.freedev.app/tools/robots-txt-generator) — write crawl rules without breaking the site.
- [Redirect Checker](https://tmlseo.freedev.app/tools/redirect-checker) — follow a redirect chain hop by hop.
- [Canonical URL Checker](https://tmlseo.freedev.app/tools/canonical-url-checker) — catch canonicals pointing at the wrong version.
- [Schema Markup Generator](https://tmlseo.freedev.app/tools/schema-markup-generator) — JSON-LD structured data you can paste.
